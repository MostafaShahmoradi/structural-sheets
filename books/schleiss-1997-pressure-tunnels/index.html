مشاهده راهنمای پایتون

📌 خلاصه مبانی تئوری و مدل هیدرومکانیکی اشلایس (README.md)

طراحی پوشش‌های بتن‌آرمه برای تونل‌ها و شفت‌های انتقال آب تحت فشار، تحت تاثیر اندرکنش شدید سازه‌ای و ژئوتکنیکی قرار دارد. پروفسور اشلایس در مدل مشهور خود، کل محیط را به **سه زون استاتیکی-هیدرولیکی** تقسیم می‌کند:

  • پوشش بتنی ترک‌خورده: که در آن بازشدگی ترک‌ها تعیین‌کننده دبی نشتی نهایی است.
  • توده سنگ مجاور تحت تاثیر جریان نشت: که فشار آب روی دیواره‌ها و تنش آن را تغییر می‌دهد.
  • توده سنگ بکر دوردست: که بدون تغییرشکل هیدرولیکی، تکیه‌گاه نهایی کل شفت است.

توزیع تنش کششی در میلگردها و بتن بین دو ترک به صورت **سهموی** محاسبه می‌شود. به علت پدیده چسبندگی (تنش پیوند)، تنش بتن در وسط دو ترک بیشینه شده و در صورت تجاوز از مقاومت کششی، سری‌های جدید ترک شکل می‌گیرند.

توزیع تنش بین دو ترک متوالی
اثر آرایش آرماتوربندی بر عرض ترک

🐍 راهنمای استفاده و اجرای اسکریپت آفلاین پایتون (`pressure_tunnel_calc.py`)

اسکریپت آفلاین پایتون به صورت شیءگرا طراحی شده و الگوریتم تکرارشونده ۸ مرحله‌ای اشلایس را برای ارزیابی پایداری و نفوذپذیری سازه‌ای حل می‌کند.

📋 نیازمندی‌های سیستم برای اجرا:

  • نصب بودن پایتون نسخه 3.8 یا بالاتر
  • نصب بودن کتابخانه ریاضی علمی numpy (در صورت عدم نصب، دستور زیر را در خط فرمان وارد کنید):
pip install numpy

🚀 شیوه فراخوانی و استفاده در کدهای شخصی:

با ایمپورت کردن کلاس طراحی، می‌توانید پارامترهای هندسی متغیر پروژه خود را وارد کرده و خروجی بگیرید: 

from scripts.pressure_tunnel_calc import PressureTunnelDesign

# ۱. راه‌اندازی کلاس با پارامترهای ژئوتکنیکی و شعاع تونل
calc = PressureTunnelDesign(
    r_i=1.8,   # شعاع داخلی پوشش به متر
    r_s=1.9,   # تراز قرارگیری میلگردها
    r_o=2.1,   # شعاع خارجی پوشش بتنی
    E_r=4.0    # مدول سنگ به گیگاپاسکال
)

# ۲. اجرای فرآیند محاسبات کوپله برای فشار آب مشخص، گام آرماتوربندی و قطر میلگرد
results = calc.calculate_state(
    p_i_bar=30,          # فشار آب داخلی (بار)
    spacing_cm=16,       # فاصله میلگردها (سانتی‌متر)
    bar_diameter_mm=18   # قطر میلگردهای انتخابی (میلی‌متر)
)

print(results)

💡 درس طلایی مهندسی در خروجی این فایل:

اگر خروجی محاسبات را برای دو فاصله میلگرد ۳۴ سانتی‌متر و ۱۶ سانتی‌متر مقایسه کنید، مشاهده می‌کنید که علیرغم استفاده از درصد فولاد یکسان، میلگردهای نزدیک‌تر عرض ترک را تا ۷۰ درصد کاهش داده و از مرز تخریب سازه‌ای دور نگه می‌دارند.

🐍 راهنمای قدم‌به‌قدم اجرای کدهای پایتون (مخصوص کاربران کاملاً مبتدی)

اگر تا به حال اسم پایتون (Python) را نشنیده‌اید و اولین بار است که می‌خواهید کدهای برنامه‌نویسی را اجرا کنید، اصلاً نگران نباشید! پایتون یک زبان فوق‌العاده ساده است که مانند یک دستیار هوشمند، کارهای سخت ریاضی را برای شما انجام می‌دهد. راهنمای تصویری و بسیار ساده زیر را دنبال کنید تا در کمتر از ۵ دقیقه گزارش‌های اکسل و نمودارهای باکیفیت طراحی خود را دریافت کنید.

گام اول

دانلود و نصب پایتون (ساده‌ترین روش)

۱. وارد سایت رسمی دانلود پایتون شوید و روی دکمه بزرگ زرد رنگ Download Python کلیک کنید تا دانلود شود.
۲. روی فایل دانلود شده کلیک کنید تا پنجره نصب باز شود.

⚠️
نکته بسیار حیاتی برای شروع کار: در پایین اولین صفحه پنجره‌ی نصب پایتون، حتماً تیک گزینه Add Python to PATH (یا Add python.exe to PATH) را بزنید! اگر این تیک را نزنید، سیستم شما دستورات پایتون را نخواهد شناخت. پس از زدن تیک، روی دکمه Install Now کلیک کنید تا نصب تمام شود.
گام دوم

باز کردن خط فرمان سیستم (CMD)

خط فرمان پنجره‌ای سیاه رنگ است که دستورات متنی شما را دریافت و اجرا می‌کند:
در ویندوز: کلیدهای Windows + R روی کیبورد را فشار دهید، کلمه cmd را تایپ کرده و کلید Enter را بزنید.
در مک / لینوکس: برنامه Terminal را در برنامه‌های خود جستجو و باز کنید.

گام سوم

ورود به پوشه اسکریپت‌ها

شما باید مسیر پوشه‌ای که کدهای پروژه در آن دانلود شده‌اند را به خط فرمان معرفی کنید.
پوشه scripts را که در پروژه دارید باز کنید، روی نوار آدرس بالای پنجره پوشه کلیک کنید و آدرس متنی آن را کپی کنید. سپس در خط فرمان ابتدا کلمه cd را تایپ کرده، یک فاصله بگذارید، مسیر کپی شده را پیست کنید و Enter بزنید: 

cd C:\Users\shahm\OneDrive\Desktop\schleiss-1997-pressure-tunnels\scripts
گام چهارم

نصب ابزارهای ریاضی و گزارش‌نویسی (فقط یک بار)

کدهای پایتون برای رسم نمودار و ساخت خودکار فایل اکسل فرمت‌یافته، به سه ابزار کمکی استاندارد نیاز دارند. دستور زیر را دقیقاً در خط فرمان کپی کرده و Enter بزنید تا دانلود و نصب شوند (کمتر از ۱ دقیقه زمان می‌برد): 

pip install numpy openpyxl matplotlib
گام پنجم

اجرا و گرفتن خروجی‌های شگفت‌انگیز اکسل و نمودار!

ابزار اول · شبیه‌ساز و نشت‌سنج

اجرای شبیه‌ساز و ساخت فایل اکسل حساسیت نشت

این دستور کل الگوریتم ۸ گام هیدرومکانیکی اشلایس را برای فشارهای ۰ تا ۵۰ بار حل کرده و فایل اکسل محاسباتی شرطی Schleiss_Pressure_Tunnel_Design.xlsx و نمودارهای Lining_Design_Chart.png را مستقیماً در پوشه شما می‌سازد. 

python pressure_tunnel_calc.py
ابزار دوم · بهینه‌ساز هوشمند آهن‌آلات

اجرای الگوریتم هوشمند بهینه‌ساز آرماتورها

python pressure_tunnel_optimizer.py
