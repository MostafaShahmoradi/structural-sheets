# دفتر محاسبات سازه (Structural Sheets)

یک ریپازیتوری واحد روی GitHub Pages برای همه کتاب‌های طراحی. هر کتاب یک پوشه داخل `books/` است و هر بخش محاسباتی آن کتاب یک زیرپوشه مستقل.

## ساختار پوشه‌ها

```
structural-sheets/
├── index.html                      ← صفحه اصلی: فهرست همه کتاب‌ها
├── assets/
│   └── style.css                   ← طراحی مشترک همه صفحات (یک‌بار ساخته می‌شود)
├── books/
│   ├── aci-318/                    ← کتاب ACI 318 (بتن آرمه)
│   │   ├── index.html              ← فهرست بخش‌های این کتاب
│   │   └── beam-flexure/           ← یک بخش محاسباتی (طراحی خمشی تیر)
│   │       ├── index.html
│   │       └── script.js
│   ├── aisc-360/                   ← کتاب بعدی (فولاد) — همین الگو تکرار می‌شود
│   │   ├── index.html
│   │   └── ...
│   └── mabhas-9/                   ← کتاب بعدی (مبحث نهم)
│       └── ...
└── README.md
```

**قانون ساده:** هر فایل HTML، صرف‌نظر از عمق پوشه‌اش، با همین خط به استایل مشترک وصل می‌شود — فقط تعداد `../` را متناسب با عمقش تنظیم کن:
```html
<link rel="stylesheet" href="../../assets/style.css">   <!-- برای books/کتاب/بخش/index.html -->
<link rel="stylesheet" href="../assets/style.css">       <!-- برای books/کتاب/index.html -->
<link rel="stylesheet" href="assets/style.css">           <!-- برای index.html اصلی -->
```

## راه‌اندازی روی GitHub Pages (یک‌بار)

1. وارد حساب گیت‌هابت شو و یک ریپازیتوری جدید بساز (مثلاً `structural-sheets`)، نوعش را **Public** انتخاب کن.
2. داخل ریپازیتوری، از **Add file → Upload files** استفاده کن و کل محتوای این پوشه (با حفظ ساختار زیرپوشه‌ها) را بکش و رها کن، سپس **Commit changes** بزن.
   - اگر فایل‌ها را به‌صورت zip داری، اول آن را روی سیستمت Extract کن و سپس محتوایش را (نه خود فایل zip را) آپلود کن.
3. برو به **Settings → Pages**.
4. زیر «Build and deployment»، گزینه **Source** را روی **Deploy from a branch** بگذار، شاخه (Branch) را **main** و پوشه را **/ (root)** انتخاب کن، سپس **Save** بزن.
5. بعد از ۱ تا ۲ دقیقه سایت در آدرس زیر بالا می‌آید:
   ```
   https://USERNAME.github.io/structural-sheets/
   ```

## افزودن یک کتاب جدید

1. یک پوشه جدید داخل `books/` بساز، مثلاً `books/aisc-360/`.
2. یک `index.html` مشابه `books/aci-318/index.html` بساز (فهرست بخش‌های آن کتاب به‌شکل جدول).
3. لینک استایل را با تعداد درست `../` تنظیم کن: `<link rel="stylesheet" href="../../assets/style.css">`.
4. یک ردیف جدید برای این کتاب به جدول در `index.html` اصلی (ریشه سایت) اضافه کن.

## افزودن یک بخش جدید داخل یک کتاب موجود

1. داخل پوشه همان کتاب، یک زیرپوشه جدید بساز، مثلاً `books/aci-318/shear-design/`.
2. یک `index.html` مشابه `books/aci-318/beam-flexure/index.html` بساز (کپی کن و ورودی/خروجی‌ها را عوض کن).
3. منطق محاسباتی را در یک `script.js` مستقل بنویس.
4. یک ردیف جدید به جدول `books/aci-318/index.html` اضافه کن و وضعیت را از «به‌زودی» به «آماده» تغییر بده.

## نکته
این ابزارها برای پیش‌طراحی و آموزش هستند و جایگزین محاسبات و مهر مهندس دارای پروانه نیستند.
